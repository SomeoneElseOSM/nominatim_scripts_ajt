Britain and Ireland Nominatim server
How to use this server

This server supports search calls like https://h36.atownsend.org.uk/nominatim/search?q=exton and https://h36.atownsend.org.uk/nominatim/search?q=52.7,-0.65. Regions ("admin_level=5") have that "admin_level" removed and Ceremonial Counties are used instead. Ceremonial counties exist in most of England and parts of Wales. They will appear in some search results, depending on what other areas are mapped at what admin level.

The server only works over IPV6 and only via https. If you can see this page, you can access it via IPV6.

Only data for United Kingdom has been loaded initially. It is hoped to increase coverage to include the rest of Ireland later.

Usage Policy

Not for commercial use. If you need a commercial service, look elsewhere.

Don't do anything like the "problematic behaviours" listed here. No scraping. You must pass a valid user agent. There is no SLA, so don't complain if it is no longer available (temporarily or permanently). Downtime is expected for database reloads. Problematic users will be blocked, and if they obfuscate their origin it will result in the the server no longer being public for everyone else.

If I use this server, what will people know about me?

I am the only person that I've set up to have access to this server. If you request data then the normal Linux logs and the Nominatim logs will record the fact. I can't comment on who might be watching traffic between you and the server (in Germany). If you're particularly worried about people NOT knowing I recommend that you set up your own server and serve everything from there instead.
